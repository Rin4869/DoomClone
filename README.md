# DOOM 1993 Clone

A simple **DOOM (1993) clone** made by a team of 4 students using **Unity and C#**.

## Features

* FPS movement
* Shooting system
* Enemies
* Weapons
* Basic level design
* Health & damage


## Reference

This project was created for educational purposes based on Unity tutorials and learning resources.
